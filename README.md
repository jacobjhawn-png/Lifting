# Lift Progression

A mobile-friendly Push / Pull / Legs / Upper / Lower workout tracker.

## Features
- Editable movements for every training day
- Weight, reps, and completed-set logging
- Progressive-overload recommendations based on the previous session
- Estimated strength progress versus the user's baseline
- Workout history stored locally in the browser

## Updating from ChatGPT
This repository is the canonical source for the lifting website. Future feature requests can be applied directly to this repository when GitHub is connected.

## Hosting
The site is static and can be hosted with GitHub Pages from the repository root on the main branch.
